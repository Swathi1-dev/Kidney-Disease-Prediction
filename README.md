# Chronic Kidney Disease Prediction 🩺

This project uses machine learning techniques to predict whether a patient has chronic kidney disease (CKD) or not, based on various medical features.

## 📁 Dataset
- 400 records
- 25 features + 1 target (classification: `ckd` or `notckd`)
- Data contains missing values and categorical attributes

## ⚙️ Workflow
- Data Cleaning & Imputation
- EDA (visualizations and feature understanding)
- Statistical Testing
- Model Building (Logistic Regression, Random Forest, etc.)
- Evaluation (Confusion Matrix, ROC-AUC, Accuracy)

## 📊 Models Implemented
- Logistic Regression
- Decision Tree
- Random Forest
- SVM
- KNN
- Naive Bayes
- XGBoost (Optional)
